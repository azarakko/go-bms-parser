# go-bms-parser

Go言語で書かれたBMS/BME/BMSONファイルフォーマットのパーサーです。

このプロジェクトは、音楽ゲームクローンや関連ツールでの使用を目的とした、Be-Music Source (BMS, BME) および bmson ファイルフォーマットのための、堅牢で効率的なパーサーを提供します。

## 主な機能（計画中）

*   BMS/BMEフォーマットのパース
*   BMSONフォーマットのパース
*   ノート、イベント、メタデータのための詳細なデータ構造
*   豊富なエラーハンドリング
